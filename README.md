## 🤖 SAM — Smart Adaptive Mentor

### Real-Time AI Desktop Assistant

**SAM (Smart Adaptive Mentor)** is a local real-time AI assistant designed to interact with the desktop through **voice, vision, reasoning, and automation**.

### ✨ Highlights

- 🎙️ Real-time voice interaction
- 👁️ Vision-enabled AI interaction
- 🧠 AI reasoning and tool dispatch
- 🖥️ Desktop automation
- ⚡ Real-time audio streaming
- 🎨 PyQt6 HUD interface
- 🔌 WebSocket-based communication
- 🛠️ Custom desktop tool execution
- 💻 Cross-platform architecture

### 🏗️ Architecture

```text
                    ┌──────────────────┐
                    │    User Input    │
                    │  Voice / Vision  │
                    └────────┬─────────┘
                             │
                             ▼
                    ┌──────────────────┐
                    │ Audio / Vision   │
                    │    Streaming     │
                    └────────┬─────────┘
                             │
                             ▼
                    ┌──────────────────┐
                    │   Gemini Live    │
                    │      API         │
                    └────────┬─────────┘
                             │
                             ▼
                    ┌──────────────────┐
                    │ AI Reasoning &   │
                    │  Tool Dispatch   │
                    └────────┬─────────┘
                             │
                 ┌───────────┴───────────┐
                 ▼                       ▼
        ┌─────────────────┐     ┌─────────────────┐
        │ Desktop Actions │     │ Vision / Screen │
        └────────┬────────┘     └────────┬────────┘
                 │                       │
                 └───────────┬───────────┘
                             ▼
                    ┌──────────────────┐
                    │  Voice / Visual  │
                    │     Response     │
                    └──────────────────┘
```
